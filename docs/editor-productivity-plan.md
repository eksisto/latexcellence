# 编辑器生产力改造设计方案（editor v2）

> **状态：共识已定稿，分阶段实施中（阶段一多缓冲区基座已实施，形态见
> [modules/editor.md](modules/editor.md)）。** 本文记录「编辑器从可用到生产力工具」改造的
> 完整设计共识（经 grilling 三轮拷问收敛），作为分阶段实施的依据与变更对照
> 基线。v1 设计见 [editor-plan.md](editor-plan.md)，已实施形态见
> [modules/editor.md](modules/editor.md)。如行为与本文冲突，先修订本文再动代码。

## 1. 背景与目标

编辑器 v1 完成了"打开-编辑-保存-冲突"闭环与命令快速输入、AI 助手，但存在
两个结构性限制，使其停留在"能用"而非"好用"：

1. **单文件缓冲区**：一次只能打开一个文件，脏文件切换只有"放弃并打开"
   一条路，与 LaTeX 写作天然多文件（主文件 + 章节 + bib）的工作流冲突；
2. **写作反馈缺失**：编辑过程中没有语法诊断、公式预览、错误行定位等反馈，
   一切都要等"编译一次看右栏"。

本方案以**多缓冲区基座**为先导，补齐编辑基本功与写作反馈闭环，把 `/editor`
页提升为可日常写作的生产力工具。

## 2. 范围与非目标

### 范围

- 多缓冲区（多标签页）基座：tab 条、per-tab 缓冲区状态、陈旧检测、关闭
  三选、刷新恢复、自动保存与编译/助手联动的多缓冲区语义；
- 编辑基本功：包裹命令、多光标、`\begin`/`\end` 自动配对、查找替换面板
  主题化与本地化；
- 大纲导航面板（当前缓冲区）；
- `\ref` / `\label` / `\cite` 引用补全（配套后端符号扫描端点）；
- 一键格式化（配套后端格式化端点，零写盘）；
- KaTeX 公式悬停预览；
- 编译错误列表与跨文件跳转（配套日志文件栈解析）。

### 非目标（记入 roadmap，本轮明确排除）

- stex StreamLanguage → MIT 许可的 Lezer LaTeX 语法（精确高亮、折叠、缩进
  的前提；`language.js` 抽象层已为此预留唯一入口）；
- SyncTeX 正反向同步（PDF ↔ 源码互跳，需编译链路加 `-synctex=1`）；
- 用户自定义片段库；
- 实时语法诊断（前端配平检查 / chktex 集成，与 Lezer 语法升级一并评估）；
- 实时协同编辑、冲突 diff 合并视图（沿袭 v1 非目标）。

## 4. 实现层既定决策（不另行拷问）

- **多缓冲区模型**：单 CM6 实例 + 每文件独立 `EditorState` 交换（天然获得
  per-tab 撤销历史与滚动位置；外部整缓冲区替换仍经 store 单向流入，
  `SessionEditor` 隔离层与"A2 按键渲染解耦"保持不变）。
- **多光标**：放开 `allowMultipleSelections`，默认开启，无偏好开关。
- **大纲条目**：`\section` / `\subsection` / `\subsubsection` / `\paragraph`
  四级缩进展示。
- **KaTeX 支持范围**：行内 `$...$` / `\(...\)`，display `\[...\]` 与
  equation/align 系环境（识别逻辑与 `formulaWrap.js` 同源思路）。
- **格式化语义**：端点为纯转换（内容进出、零写盘、零配额影响），前端应用
  后只置脏，落盘仍走 save-file 单一路径；viewer 禁用入口。
- **URL `?file=`**：跟随激活 tab；刷新时与 sessionStorage 恢复结果合并
  （恢复全部 tab 集合，`?file=` 指定者激活）。
- **后端撤销/重做**：工具栏按钮绑定活跃 tab 的文件；"脏改动时禁用后端
  历史"的既有规则不变。
- **tab 数量**：不设硬上限，sessionStorage 配额由 LRU 淘汰策略兜底。
- **全部保存**：tab 条在多于一个脏 tab 时提供"全部保存"入口。

## 5. 总体设计

### 5.1 多缓冲区基座（阶段一）

`editorStore` 的 `editorSession` 切片从单文件模型重构为多缓冲区模型：
per-tab 维护 `{ filePath, buffer, baseMd5, dirty, stale, cursor/scroll }`，
激活 tab 的 content 仍经 `SessionEditor` 单点订阅流入 CM6。tab 间切换 =
`EditorState` 交换，撤销历史与滚动位置随 `EditorState` 天然隔离。

- **陈旧检测**：激活 tab 时调 `GET /api/project/file-md5` 与 `baseMd5`
  比对（复用检查结果保鲜的"MD5 比对 + 只提示不销毁"模式），不一致时 tab
  上显示"磁盘已变更"标记，保存前经确认；保存时 409 冲突流程照旧兜底。
- **关闭脏 tab**：三选弹窗（保存并关闭 / 放弃改动 / 取消）。
- **刷新恢复**：打开的 tab 集合与脏缓冲区全文连同 `baseMd5` 写
  sessionStorage；刷新后恢复 tab 集合与脏标记（磁盘内容以缓冲区为准，若
  期间磁盘被改，乐观锁在保存时兜底）。超配额（约 5MB）按 LRU 淘汰最久
  不活跃的非脏 tab；全脏超限时 toast 提示保存。
- **自动保存**：per-tab 防抖器，所有脏 tab 停改 2.5s 落盘（`autoSave`
  偏好开启时）。
- **编译联动**：编译前依次自动保存所有脏 tab，任一 409 即中断并进入该
  tab 的冲突流程（`useEditorCompile` 的保存前置从单次扩展为按 tab 顺序）。
- **AI 助手**：助手上下文与建议卡片携带发送时的来源 filePath；应用建议时
  若活跃 tab 不匹配则禁用按钮并提示切换（纯前端改动）。

### 5.2 后端新增（阶段四 / 阶段五）

| 接口 | 语义 |
| --- | --- |
| `GET /api/project/latex-symbols` | 只读符号扫描：遍历项目内 `.tex` 提取 `\label`（含行号）与 `\cite` key，`.bib` 文件经 `bib_parser.py` 提取条目 key；路径校验复用 `resolve_project_path()`，扫描经 `asyncio.to_thread()`；响应只含相对路径（多用户脱敏）；零 LLM |
| `POST /api/project/format-latex` | 纯转换：接收缓冲区内容，内部复用 `latex_formatter`（latexindent 优先、内置兜底，外部命令执行沿既有 SandboxRunner 规则）返回格式化结果；不落盘、不涉路径、零配额影响 |

### 5.3 前端增量（阶段二至七）

- **编辑基本功**（阶段二）：包裹命令快捷键 + Ctrl+L 浮层菜单（数据源为
  `data/latexCommands` 新增 wrap 类目，顺带进四路匹配索引与命令面板）；
  放开多光标；`\begin{env}` 敲完打字机补 `\end`（曾配对不再补）；
  CM6 搜索面板主题化 + 三语 i18n。
- **大纲面板**（阶段三）：`outlineScan.js` 纯模块（可 node --test 单测）
  解析分节命令，左栏双 tab，编辑防抖增量重扫，点击滚动定位。
- **引用补全**（阶段四）：`\ref{` / `\label{` / `\cite{` 触发的补全
  source，复用现有补全弹层主题；符号缓存以项目为键，保存成功后失效重拉。
- **格式化**（阶段五）：工具栏按钮 + 快捷键，应用结果全文替换缓冲区并
  toast 提示 Ctrl+Z 可撤销。
- **KaTeX 悬停**（阶段六）：CM6 hover tooltip 插件；katex 动态 import
  分块（沿用 pinyin-pro / opencc-js 的懒加载先例）；实施时同步更新
  `THIRD_PARTY_NOTICES.md`（katex，MIT）。
- **编译错误跳转**（阶段七）：日志文件栈解析纯模块（`(./` 压栈、`)` 弹栈、
  `l.N` 归属栈顶文件；转义括号等歧义保守回落当前缓冲区并标低置信），
  右栏错误列表可点击，跨文件跳转 = 联动打开对应 tab 并定位行首高亮。

### 5.4 偏好增量

`EDITOR_PREFERENCES_DEFAULTS` 新增 `formulaHover` / `autoCloseEnv`
（默认均开），随既有白名单清洗、导入导出校验、设置弹窗与三语 i18n 一并
生效。**不新增 `config.json` 配置项**，无四处配置同步负担；`editor.enabled`
/ `assistant_enabled` 服务端开关语义不变。

## 6. 阶段划分与验收

| 阶段 | 内容 | 验收要点 |
| --- | --- | --- |
| 一：多缓冲区基座 | tab 条、per-tab EditorState/撤销/滚动、陈旧检测、关脏三选、刷新恢复、per-tab 自动保存、编译全量脏保存、助手 tab 守卫 | 多文件互不串缓冲区；Ctrl+Z 按文件隔离；陈旧标记正确出现/消除；刷新恢复脏内容且乐观锁仍兜底；编译包含后台 tab 改动 |
| 二：编辑基本功包 | 包裹直包 + 浮层菜单、多光标、`\begin` 自动配对（含开关）、查找替换本地化 | 包裹/配对行为与开关一致；多光标默认可用；搜索面板三语无英文泄漏 |
| 三：大纲面板 | `outlineScan` 纯模块 + 左栏双 tab + 防抖重扫 | 大纲与缓冲区实时同步；点击定位行首；纯模块单测覆盖 |
| 四：符号补全 | `latex-symbols` 端点 + 三个补全 source + 缓存失效 | 跨文件 `\ref` 命中；`.bib` key 命中；保存后缓存刷新；响应无绝对路径 |
| 五：格式化 | `format-latex` 端点 + 工具栏/快捷键入口 | 格式化结果只进缓冲区不落盘；Ctrl+Z 可完整撤销；viewer 禁用 |
| 六：KaTeX 悬停 | hover tooltip + katex 动态分块 | 悬停渲染正确；首屏零 katex 加载；开关生效；`THIRD_PARTY_NOTICES.md` 更新 |
| 七：错误跳转 | 日志栈解析纯模块 + 右栏错误列表 + tab 联动 | 子文件错误跳转正确；歧义回落标低置信；解析模块单测覆盖 |

阶段一必须独立先行（改动面最深）；二至七相互无依赖，可按序推进。

## 7. 全局约束（每阶段适用）

- 所有落盘仍走 save-file 单一路径 + MD5 乐观锁；格式化、补全、预览、
  符号扫描零写盘。
- 新端点响应不返回绝对路径（多用户脱敏）；面向用户的错误消息只用相对
  路径，并同步三语 `errors` 命名空间。
- 新增纯模块一律 node --test 单测；后端新增端点补 `tests/test_api/`
  集成测试（无 LLM，严禁真实网络）。
- 同步阻塞 I/O 与全项目扫描一律经 `asyncio.to_thread()` 调度。
- 每阶段同步更新 `docs/modules/editor.md` 与 `PROJECT_SUMMARY.md`；全部
  阶段完成后更新本文状态为"已实施"、`editor-plan.md` 非目标清单相应
  勾销、README 增量。
- commit 按阶段提交，格式 `<type>(editor): 中文描述`。
